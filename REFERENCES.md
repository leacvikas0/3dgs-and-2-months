# Academic Papers & Code References

This document lists the original publications and GitHub repositories for all libraries and models integrated throughout this project. Use these to read up on theoretical backgrounds or clone fresh forks.

  * **Link:** [arXiv:2406.09756](https://arxiv.org/abs/2406.09756)
* **Official Code:** [GitHub - naver/mast3r](https://github.com/naver/mast3r)
